# datastructure

- Rust에서 기본 제공하고 있는 표준 라이브러리 (std::collection)을 직접 구현하는 조그만 프로젝트로 직접 만들어 보고자 합니다.

## 1. 동적 배열 (Dynamic Array) 
  - 칸이 꽉 차면 더 큰 공간으로 이사하는 배열이다.
  - 그런데 데이터가 몇 개 들어올지 미리 알 수 없을 때 사용한다
    (일반 배열은 크기가 정해져 있어 나중에 더 늘릴 수 없다)

## 2. 정렬 비교
|구분    | 버블   | 선택     | 삽입     |  병합  | 힙      | 퀵     |
| ------ | ------ | -------- | -------- | ------ | ------- | ------ |
| 핵심 동작     | 이웃끼리 swap | 최솟값 골라 swap | 앞 구간에 끼워 넣기 | 쪼개고 합치기 | 최댓값 뽑아 뒤로 | 피벗 기준 분할  |
| 최악 속도 | n²    | n²     | n²      | n·log n | n·log n | n²      |
| 안정성    | 안정  | 불안정 | 안정    | 안정    | 불안정  | 불안정  |
| 추가 메모리 | 없음 | 없음  | 없음 | 필요 | 없음 | 호출 스택 |
| 이미 정렬된 입력|빠름|느림|빠름|그대로 | 그대로 | 피벗에 따라 최악 |

- - 참고로 실제 프로젝트에서는 표준 라이브러리의 `v.sort()`(안정)와 `v.sort_unstable()`(불안정)을 쓰는 게 보통이에요.
